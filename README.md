# MataKuliah_PBO_SistemTransaksiLaundryKiloan
Aplikasi konsol Java ini mengelola transaksi laundry kiloan menggunakan prinsip inheritance (superclass `LayananLaundry` serta subclass `CuciKering` dan `CuciSetrika`). Sistem secara otomatis menghitung total biaya berdasarkan jenis layanan dan berat pakaian yang diinput.
